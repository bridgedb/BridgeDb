Plugin for org.bridgedb.rdb to use DuckDB databases as identifier mapping services.

For example, to use a downloadable DuckDB database (bridge file) as a mapping resource, you can use the following piece of code: 

	Class.forName("org.bridgedb.rdb.duckdb.IDMapperDuckDB");
	mapper = BridgeDb.connect ("idmapper-duckdb:path/to/file.bridge");
