Driver and helper classes for using relational databases as identifier mapping services, backed by DuckDB instead of Apache Derby.

For example, to use a downloadable DuckDB database (pgdb file) as a mapping resource, you can use the following piece of code: 

	Class.forName("org.bridgedb.rdb.duckdb.IDMapperRdb");
	mapper = BridgeDb.connect ("idmapper-pgdb:path/to/file.duckdb");
