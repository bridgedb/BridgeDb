Plugin for org.bridgedb.rdb to use MySQL and MariaDB databases as identifier mapping services.

It adds the MySQL JDBC driver, which org.bridgedb.rdb no longer depends on. With this plugin, you can use a database on a MySQL or MariaDB server as a mapping resource with the following piece of code: 

	Class.forName("org.bridgedb.rdb.IDMapperRdb");
	mapper = BridgeDb.connect ("idmapper-jdbc:mysql://host/database");
