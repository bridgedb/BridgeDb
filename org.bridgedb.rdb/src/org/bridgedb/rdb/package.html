Driver and helper classes for using relational databases as identifier mapping services.

This package does not depend on a particular database. For example, to use any database for which a JDBC driver is available as a mapping resource, you can use the following piece of code: 

	Class.forName("org.bridgedb.rdb.IDMapperRdb");
	mapper = BridgeDb.connect ("idmapper-jdbc:mysql://host/database");
Support for Derby databases (pgdb and bridge files) is provided by the plugin org.bridgedb.rdb.derby, for DuckDB databases by the plugin org.bridgedb.rdb.duckdb.
