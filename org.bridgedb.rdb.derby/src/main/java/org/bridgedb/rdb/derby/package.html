Plugin for org.bridgedb.rdb to use Apache Derby databases as identifier mapping services.

For example, to use a downloadable Derby database (pgdb or bridge file) as a mapping resource, you can use the following piece of code: 

	Class.forName("org.bridgedb.rdb.derby.IDMapperDerby");
	mapper = BridgeDb.connect ("idmapper-pgdb:path/to/file.bridge");
